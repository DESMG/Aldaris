# 页面手工测试清单

本文供测试人员直接操作页面。只需点击、输入、上传图片、刷新，以及使用浏览器的前进和后退。所有项目都从"未测"开始。

## 开始前准备

由提供测试任务的人交付以下材料；缺少时记录"无法测试"，不用自行搭建或制作特殊数据。

- 测试网址和本次测试的版本名称。
- 两个管理员账号、两个普通用户账号，以及可修改密码、可删除的专用测试账号。账号之间的密码通过单独渠道交付。
- 一份长标题、长正文、长姓名和长用户名的测试文本。
- 正常横图、竖图、透明图片各一张，10 张可一起上传的图片，以及标明"应拒绝"的超大、损坏、动图或不支持格式的文件。处理前图片每张不超过 20 MiB、单边不超过 3840 像素、总像素不超过 8294400；提供各项恰好达到限制与略超限制的样本。另准备细节较多的横图、竖图和正方形图片，以及带有可核对元数据的 JPG 和 PNG；无法准备时将对应项目标为"无法测试"。
- 一个没有评论的工单、一个只有少量评论的工单、一个有超过 60 条评论和操作记录的工单。
- 长工单中两条中间评论的定位链接。提供者应把这两个链接放在工单正文中，方便连续点击。
- 如需检查图片被清理后的显示，提供含有已清理图片的测试工单。

只操作专用测试数据。删除用户、删除评论和修改密码前，确认目标是允许操作的测试账号或内容。

先用常用浏览器完成全部项目，再用另一个浏览器重复主要流程。有手机时也测手机；没有手机时把浏览器窗口缩窄。切换深色、浅色主题各看一遍，再用浏览器菜单把页面放大到 200%。

## 怎么记录结果

每项标为"通过"、"失败"、"无法测试"或"未测"。没有执行的项目不能标为通过。偶尔出现的问题也要记录，不需要找出原因。

发现问题时填写：

- 测试编号：
- 使用的浏览器和设备：
- 使用管理员还是普通用户：
- 操作的工单或评论：
- 依次做了什么：
- 本来应该看到什么：
- 实际看到了什么：
- 能否再次出现：
- 截图或录屏：

不要在截图或记录中展示密码。遇到看不懂的提示，照原样记录；测试人员不用决定要不要修复。

## 登录、退出和密码

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 登录-1 | 用提供的正确账号和密码登录，刷新页面，再新开一个标签页进入测试网址 | 登录成功，刷新和新标签页显示同一账号 |
| 登录-2 | 退出后，输入一次错误密码；再输入正确密码 | 错误密码有明确提示，正确密码可以登录 |
| 登录-3 | 连续输错密码 3 次，再尝试登录；按提示等待后重试 | 多次失败后提示稍后重试，等待结束后可恢复；同一网络其他测试人员可能一起受影响，执行前先协调 |
| 登录-4 | 在尚未触发等待限制时，输错 2 次后正确登录；退出，再正确登录 | 成功登录后可以正常继续使用，不因前两次失败一直被限制 |
| 登录-5 | 登录后退出，再刷新页面，并尝试打开之前的工单链接 | 要求重新登录，不能继续进行已登录操作 |
| 登录-6 | 在账户设置中输入错误的当前密码，再尝试修改密码 | 提示失败，原密码仍可登录 |
| 登录-7 | 修改密码时，新密码与确认密码填写不同内容；再改成一致并提交 | 不一致时不能成功；修改成功后新密码可登录，旧密码不可登录 |
| 登录-8 | 设置密码时，尝试少于 6 个字符的密码；再使用符合页面要求的密码 | 太短的密码不能提交成功，提示清楚 |
| 登录-9 | 创建用户或修改密码时，如果出现密码泄露风险确认，先取消，再重新操作并确认 | 取消后保留输入且不提交；确认后可以继续。未遇到提示则记录该分支未测 |
| 登录-10 | 在另一个浏览器登录同一账号，回到原浏览器尝试保存一条测试回复 | 新浏览器可正常使用，原浏览器需要重新登录，不能继续按原登录状态保存 |

## 用户管理 (管理员执行)

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 用户-1 | 点击"用户管理"，再点"创建用户"，分别创建普通用户和管理员 | 创建成功，列表中的姓名、用户名和角色正确，新账号可以登录 |
| 用户-2 | 创建用户时留空必填项，或输入已存在的用户名 | 不能创建成功，有明确提示，已填内容不应无故消失 |
| 用户-3 | 昵称输入中文姓名；用户名输入姓名拼音及末尾数字。另试拉丁字母、空格或不支持标点组成的昵称，以及中文用户名、带空格的用户名 | 合法内容可以保存；不符合页面要求的内容不能保存 |
| 用户-4 | 分别打开几个用户的"编辑"，只修改昵称，新密码留空，保存后重新打开 | 昵称提示包含"中文真实姓名"，与创建用户时一致；昵称和用户名打开时均有正确内容；只改昵称不会改用户名或密码 |
| 用户-5 | 编辑用户，填写新密码及确认新密码并保存 | 目标账号可以使用新密码，不能再用旧密码；原登录页面再次操作时要求重新登录 |
| 用户-6 | 编辑用户的用户名并保存，再用新旧用户名分别登录 | 新用户名有效，旧用户名不能再用于这个账号；旧页面再次操作时要求重新登录 |
| 用户-7 | 打开删除用户弹窗，先取消；重新打开后确认删除专用测试账号 | 取消不删除；确认后账号不能登录，历史工单和评论仍能正常查看 |
| 用户-8 | 查看自己的用户行 | 不能通过自己的删除按钮删除当前账号 |
| 用户-9 | 搜索用户，输入完整用户名和不存在的用户名；列表较长时继续加载 | 正确用户可找到；没有匹配结果时显示清楚；继续加载不重复、不漏掉已显示内容 |
| 用户-10 | 创建用户时只切换角色，然后离开；另一次成功创建管理员后再打开创建页 | 未保存时离开有确认；新的创建表单默认角色为普通用户 |

## 普通用户能看到什么

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 权限-1 | 用普通用户登录，查看账户菜单 | 没有可用的用户管理、创建用户及操作记录管理入口 |
| 权限-2 | 从管理员浏览器复制用户管理页的地址，在普通用户浏览器中打开 | 不能查看或操作管理员用户列表 |
| 权限-3 | 普通用户打开自己和他人创建的工单 | 都可以查看内容和发表回复；修改工单属性的入口按权限显示 |
| 权限-4 | 分别查看自己的评论和他人的评论 | 普通用户只能编辑或删除自己的评论；管理员可以处理其他人的评论 |
| 权限-5 | 用两个不同账号查看同一工单和图片 | 都能正常查看，页面显示的当前账号各自正确 |
| 权限-6 | 查看工单列表和账户菜单 | 没有工单搜索框和站内通知中心；用户搜索仍可使用，提及或指派不要求产生通知 |

## 工单列表和新建工单

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 工单-1 | 切换"未关闭"和"已关闭"，翻页，刷新，再用浏览器后退和前进 | 列表状态与所选分类一致；页码、分类和地址对应，不跳到无关页面 |
| 工单-2 | 在第二页打开工单，再按浏览器后退 | 回到原列表页，分类和页码保留 |
| 工单-3 | 将当前列表地址复制到新标签页打开 | 显示相同分类和页码 |
| 工单-4 | 点"新建工单"，填写标题、正文并提交 | 创建表单不展示优先级；工单只创建一次，默认低优先级，标题、正文、作者和图片正确 |
| 工单-5 | 新建工单时留空标题，再尝试提交 | 不会创建无标题工单，页面说明需要填写 |
| 工单-6 | 粘贴准备好的长标题、长正文，包含连续中文、长英文、网址和多行文字 | 页面不被撑坏；超出限制时不能悄悄保存成错误内容；保存后换行和文字显示正常 |
| 工单-7 | 新建工单时连续快速点击提交按钮 | 不生成重复工单，不显示互相矛盾的成功和失败结果 |
| 工单-8 | 打开工单详情，再返回列表或其他页面，观察浏览器标签标题 | 详情标题对应工单，离开后不残留无关工单标题 |

## 回复、状态、优先级和负责人

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 协作-1 | 发表一条文字回复、一条带图片回复，再刷新 | 各出现一次，文字、作者、图片正确 |
| 协作-2 | 编辑自己的回复，修改文字、删除一张旧图并添加一张新图，保存后刷新 | 修改内容正确；移除的图片不再出现在该评论中，其他图片仍正常 |
| 协作-3 | 打开删除评论弹窗，先取消，再重新打开并确认删除 | 取消时评论保留；确认后评论消失，其他评论不受影响 |
| 协作-4 | 有修改权限时，分别关闭工单为"已完成"和"不计划处理"，再重新打开 | 状态、列表分类和操作记录对应，刷新后保持 |
| 协作-5 | 填写回复，再点"回复并关闭工单"；另一次不填回复，只关闭工单 | 前者只发表一次回复并关闭；后者不产生空白回复。若提示回复成功但关闭失败，先核对结果，不重复发表同一回复 |
| 协作-6 | 作者或管理员在详情侧栏依次点击"加急"，每次完成后刷新并查看列表 | 优先级从低到中、再到高，每次只提升一级；高优先级时隐藏"加急"按钮，不展示"已达最高优先级"等替代提示；详情、列表及时间线一致；其他普通用户没有加急入口 |
| 协作-7 | 编辑负责人，搜索并选择产品、开发和测试人员，然后保存 | 产品和开发可选管理员，测试可选普通用户；保存后姓名与角色正确 |
| 协作-8 | 选择 5 个不同负责人后尝试增加第 6 人；让同一管理员同时担任产品和开发 | 不能保存超过 5 个不同的人；同一个人兼任两种角色只算一个人 |
| 协作-9 | 在正文输入 @ 和用户名，点击建议中的用户；保存后将鼠标移到提及姓名上 | 建议可以选择，保存后显示正确用户；不要把提及当成私密分享，其他成员仍能看到正文 |
| 协作-10 | 输入 @ 建议时，使用上下键、回车、Esc；再用中文输入法继续写字 | 可以选择或关闭建议，中文输入不被误提交，关闭建议不会同时丢掉外层表单 |
| 协作-11 | 点击正文中的本站工单链接和外部网站链接 | 本站链接打开对应页面，外部链接打开对应网站；正文其他文字不丢失 |

## 图片选择和预览

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 图片-1 | 通过选图按钮上传横图、竖图、透明图片；再尝试粘贴图片 | 可添加的图片正常预览，透明部分显示正常；忽略 EXIF 方向标记 |
| 图片-2 | 一次选择 10 张图片，再尝试增加第 11 张；编辑带图片的评论时，保留旧图并补足到 10 张，再尝试新增 | 新图和保留旧图合计最多 10 张，每张最终不超过 1 MiB，合计不超过 10 MiB；超量时有清楚提示，不误删已选或保留图片 |
| 图片-3 | 选择准备好的"应拒绝"文件，再尝试把正常图片和这些文件一起选择 | 提示不能添加，不假装上传成功；混合选择失败时说明整批没有添加 |
| 图片-4 | 图片处理中继续输入正文，并尝试再次选图或提交 | 不重复添加或提交，处理结束后刚输入的文字不回退 |
| 图片-5 | 点击图片打开大图，拖动或滚动缩放，再关闭 | 图片可查看，关闭后回到原页面，不意外丢失正文或跳走 |
| 图片-6 | 在长页面上下滚动，多次打开并关闭图片 | 图片不串成其他图片，不一直停在加载状态，不出现重复预览层 |
| 图片-7 | 打开提供的已清理图片工单 | 原图片位置有"[图片已被清理]"提示，其他文字和图片仍正常 |
| 图片-8 | 如果自然遇到图片加载失败，使用页面上的重试操作 | 失败能被看见；恢复后可查看，仍失败时保留明确提示。没遇到失败则记录该分支未测 |
| 图片-9 | 查看图片说明，选择处理前大于 1 MiB 且不超过 20 MiB、单边不超过 3840 像素、总像素不超过 8294400 的静态 JPG 或 PNG；再分别选择略超这三项限制的样本 | 符合处理前限制的图片可添加，超限样本被拒绝且不影响原有选择；说明只展示支持静态 JPG、PNG、最终每张 1 MiB、最多 10 张和合计 10 MiB 等上传要求，不展示处理前限额、缩放、重新编码或元数据处理细节；预览和合计显示最终图片大小 |
| 图片-10 | 选择准备好的细节较多的横图、竖图和正方形图片，保存后下载结果并核对宽、高、总像素和文件大小 | 每张最终单边不超过 1920 像素、宽乘高不超过 2073600 像素、文件大小不超过 1 MiB；内容完整，PNG 透明区域保留，忽略 EXIF 方向标记；无法下载或核对的部分标为"无法测试" |
| 图片-11 | 分别复制 JPG、PNG，以及浏览器可能转换格式的截图或其他格式图片后粘贴；按页面显示的文件名、格式或错误记录剪贴板实际提供的文件 | 页面按剪贴板实际提供的 JPG 或 PNG 文件处理；剪贴板实际提供其他图片格式时明确拒绝，不根据被复制资源的扩展名作保证 |
| 图片-12 | 上传带有可核对元数据的 JPG 和 PNG，保存后下载上传结果并检查格式、元数据和透明区域 | 输出统一为静态 WebP，不保留处理前图片附带的元数据，透明区域保留；无法下载或核对元数据时将未核对部分标为"无法测试" |
| 图片-13 | 编辑带有图片的评论，依次保留旧图、添加新图、移除新图，再保存并重新编辑 | 张数同时计入保留旧图和新图；大小提示明确其统计范围，仅统计新图时不能称为全部图片合计；新增图片显示最终大小，移除后对应张数和大小同步更新 |

## 关闭弹窗、离开和草稿恢复

以下分别在新建工单、回复、编辑回复、编辑用户和创建用户中执行。负责人编辑也要测离开确认，但不要求刷新后恢复其选择。

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 草稿-1 | 打开空表单，按 Esc、点击空白背景或关闭按钮 | 有对应关闭入口时可正常关闭，不提交内容，不误关其他页面 |
| 草稿-2 | 输入文字或选择图片后离开，出现确认时选择取消 | 原页面、输入和图片仍保留 |
| 草稿-3 | 再次离开并确认，然后在同一标签页重新打开相同表单 | 提示会保留的文字可恢复；未提交图片和密码需要重新填写 |
| 草稿-4 | 输入文字后刷新，先取消浏览器的离开提示；再确认刷新并重新打开表单 | 取消后内容保留；确认刷新后文字草稿可以恢复，未提交图片需重选 |
| 草稿-5 | 在有明确"取消编辑"的表单中修改内容，然后取消编辑并确认放弃，再重新编辑 | 显示已保存内容，不恢复刚才明确放弃的修改 |
| 草稿-6 | 输入未保存内容，连续后退两次、前进两次，分别测试取消和确认离开 | 取消时地址和页面一致，内容保留；确认时正常切换，不反复弹窗或来回跳转 |
| 草稿-7 | 保存成功后正常离开；保存失败时再尝试离开 | 成功后不再误报有未提交内容；失败后输入保留，离开仍有保护 |
| 草稿-8 | 页面有弹窗和下拉菜单时，按一次 Esc，再按一次 Esc | 每次只关闭最上层可关闭的内容，不一次清空全部输入 |
| 草稿-9 | 图片处理或保存过程中尝试关闭弹窗 | 禁用的按钮不能操作；允许离开时按提示确认，不误显示保存成功 |
| 草稿-10 | 用 Tab 在表单中移动焦点，关闭弹窗后继续按 Tab | 焦点清楚可见，能继续操作页面，不被困在已关闭的弹窗中 |

## 两个页面同时操作

同一浏览器的两个标签页用于测试同账号编辑；两个不同浏览器用于分别登录不同账号。

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 同时-1 | 两个标签页打开同一评论并进入编辑，各填不同内容，先后保存 | 后保存者收到内容已更新的提示；自己的输入保留，不直接覆盖先保存的内容 |
| 同时-2 | 两个标签页打开同一用户编辑表单，各改昵称，先后保存 | 后保存者得到冲突提示；载入最新版本后可比较，需再次明确保存 |
| 同时-3 | 两个标签页同时修改工单状态、加急或修改负责人；另试两页从低优先级同时加急后重试冲突 | 不把旧内容悄悄盖掉；冲突时有提示，用户可以核对后重试；原目标已达到时重试不会继续加急到高，也不会降低优先级；重试后时间线和返回列表也与当前优先级一致 |
| 同时-4 | 页面 A 准备删除评论但先不确认；页面 B 修改并保存该评论；回到 A 确认删除 | 要求先查看最新内容，再确认是否删除，不直接删除刚更新的评论 |
| 同时-5 | 页面 A 编辑评论，页面 B 删除该评论；回到 A 尝试保存 | 明确提示评论已不存在，不能假装保存成功，其他评论正常 |
| 同时-6 | 标签页 A 填写草稿，标签页 B 退出并登录另一个账号，再回 A | 当前账号正确同步；旧账号草稿不能以新账号提交 |
| 同时-7 | 不同浏览器分别登录管理员和普通用户；普通用户写草稿时，管理员重置该用户密码，再让普通用户提交 | 要求重新登录；使用原账号重新登录后，当前页面输入应保留，不误提交 |
| 同时-8 | 上一步中尝试改用另一个账号恢复草稿，或选择放弃草稿 | 不能直接把原账号草稿交给另一账号；放弃前有确认，取消时保留 |
| 同时-9 | 如果保存尚未结束，尝试离开并确认；随后在新页面继续输入 | 完成的旧操作不把新页面拉回，不清掉新输入。回原工单核对是否已保存，不把离开当成撤销 |

## 长工单和评论定位

| 编号 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 定位-1 | 分别查看无评论、少量评论和超过 60 条记录的工单 | 无评论页面正常；长工单先显示头尾，中间有展开入口和数量 |
| 定位-2 | 在长工单中反复点击展开较早记录，直至全部展示 | 记录顺序正确、不重复，隐藏数量逐步减少，不突然跳到其他工单 |
| 定位-3 | 滚到中间再展开，观察正在看的内容 | 原内容仍能找到，不无故跳到页面顶部 |
| 定位-4 | 打开提供的评论定位链接 | 地址与目标评论对应，目标有高亮并滚动到可见位置 |
| 定位-5 | 在长工单正文中点击中间评论 B 的链接，再点 A 的链接，等内容出现后迅速点回 B；尽量在 5 秒内完成 | 最后应看到 B 并滚动到 B，不能只改变地址和高亮却留在页面顶部。期间不要展开其他记录或保存内容；另等 10 秒再重复，对比结果 |
| 定位-6 | 复制一条测试评论的定位地址，删除该评论，再打开复制的地址 | 明确提示评论已删除或不可用，工单其他内容仍能查看 |
| 定位-7 | 编辑中间评论时点击另一条评论链接，先取消离开，再重试并确认 | 取消时原编辑内容和地址保留；确认后正常定位，仍可回复、编辑和展开 |
| 定位-8 | 在两条评论之间用浏览器后退和前进 | 页面与地址一致，不显示无关评论，不重复叠加内容 |

## 自由探索

按自己平时的使用习惯再完整操作一轮。可以反复开关弹窗、快速切换页面、换着顺序编辑、复制粘贴文字、连续点击按钮，以及在多个标签页之间切换。

重点记录：输入丢失、重复保存、提示与结果不一致、操作了错误对象、无法返回、按钮点不动、页面一直转圈、图片串图和文字看不清。不要只记"不好用"，尽量留下能让别人照做的步骤。
